# Sun Xinyuan - Personal Website

Personal homepage, project case studies, resume, and technical writing for
[sunxi2077.github.io](https://sunxi2077.github.io).

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```

Pushes to `main` are built and deployed automatically with GitHub Actions.

Built with [Astro](https://astro.build). The original interface is based on the
[Ryze](https://github.com/A58361/Ryze) starter.
